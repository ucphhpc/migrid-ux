Account Requests Management

Here you can manage account requests. Reject requests, forward them to a peer contact, and finally the create user.

Account Request Query ?
Case insensitive free text search of account requests applied to every field.
Account Request State ?
An account request can be either:
Requested if an external user has created it, but it has not been forwarded yet.
Pending if it has been forwarded, but not yet accepted by the peer contact.
Accepted if it has been accepted by the peer contact, but not yet created by a supporter or operator.
