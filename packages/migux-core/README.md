# @migrid/migux-core

Foundation library for MiGrid-UX — a browser runtime for building dynamic web
applications with observable-based state and DOM binding. General documentation for this can be found in the [main project documentation](https://github.com/ucphhpc/migrid-ux).

## Installation

```sh
npm install @migrid/migux-core
```
